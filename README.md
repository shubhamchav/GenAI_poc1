# Terraform AWS Provider POC

This project demonstrates a simple Terraform configuration using an outdated AWS provider version for dependency update automation testing.

## Usage
1. Initialize Terraform:
   ```sh
   terraform init
   ```
2. Plan the deployment:
   ```sh
   terraform plan
   ```
3. Apply the deployment:
   ```sh
   terraform apply
   ```

## Purpose
This POC is intended for testing automated dependency update tools. The AWS provider version is intentionally outdated.
